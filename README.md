# 工业机械臂装配线仿真 — 轮毂装配线 LINE-01（三机协同）

基于 Three.js 和 TypeScript 构建的**三工位汽车轮毂装配流水线**仿真。三台六自由度
机械臂沿主输送线排布，各司一道工序：**ST1 装刹车盘 → ST2 装轮毂总成 → ST3 装中心
锁紧螺母并拧紧**。装配托架在主线上依次流经三个工位，三台机器人并行作业、互锁协同，
成品从线尾连续下线。

当前版本：**2.1.0**

## 产线布局与工艺

```text
每工位:  线边来料线(沿 z, 单一零件) ──> 光电到位 ──> 在线视觉识别 ──> 机械臂
主  线:  空托架 ─> ST1 装盘 ─> ST2 装毂 ─> ST3 装螺母+拧紧 ─> 成品下线(沿 x)
```

每个工位的循环：来料到位 **且** 托架就位（互锁）→ 视觉识别（标识色 → 零件类型 +
反投影位置，错料退回）→ 多种子 IK 轨迹规划 → 抓取 → 装配落座 → （ST3 拧紧 +
火花）→ 托架放行 → 下一循环。空托盘在拾取位下沉回流，不与任何线体交叉。

## 三机协同与冲突解决

- **空间冲突**：工位间距（2.2 m）大于单臂作业包络，三臂可同时运动互不侵入；
  每台机器人的轨迹规划仍把邻站输送线、主线、邻站机器人立柱全部作为碰撞障碍。
- **逻辑互锁**：托架只有在本站机器人完成装配并放行后才向下游移动；工位只有在
  "零件到位 && 托架到位且前序工序完成"时才开始动作；主线托架间保持最小间距。
- **流水线节拍**：三工位重叠作业，整线节拍 ≈ 单工位循环时间（实测 ~10s/台，
  约为单机方案的 3 倍产能）。

## 功能

- 三台六自由度机械臂并行作业，各配独立来料线、固定相机与工位控制器
- 主装配线：托架队列、工位停靠互锁、成品下线统计（产量 / 在制 / 节拍）
- 三种程序化建模的汽车零件：通风刹车盘、五辐轮毂总成（带轮胎）、中心锁紧螺母
- 来料线：滚动皮带纹理、托盘队列、止动器、光电传感器状态灯、空托盘下沉回流
- 在线视觉（每工位一台相机）：从渲染像素做 HSV 三色分割（红/蓝/黄标识）、
  连通域检测、反投影定位；错料 / 低置信度退回、视野遮挡安全停机
- 工位控制器状态机：待料 / 识别 / 规划 / 抓取 / 装配 / 拧紧，抓取失败重试，
  停线班报（下线数 / 装配件数 / 节拍 / 退料）
- 碰撞安全：自碰撞、地面间隙、全线设备障碍盒（含邻站）、全轨迹采样验证
- 工厂视觉效果：环氧地坪与警戒线、安全围栏、每工位安灯塔与状态屏、顶灯阵列、
  环境反射（PMREM）、UnrealBloom 辉光、落座光环与拧紧火花、可选环绕镜头
- 页面切到后台时产线继续运行（Web Worker 心跳，不受浏览器节流影响）

## 在线视觉

在线识别不读取零件的真实位置或类型，每工位相机每次观察：

```text
固定工位相机渲染 320x240
  -> 读取 RGBA 像素
  -> HSV 分割（红=刹车盘 / 蓝=轮毂 / 黄=螺母）
  -> 连通域分析 + 相邻标识拆分
  -> 像素质心反投影到标识平面
  -> 本工位拾取窗口过滤 -> 生成检测结果
```

控制器只信任拾取窗口内、且与光电到位信号一致的检测；识别类型与本工位工序不符时
零件被退回（错料防呆）。左上角面板显示所选工位的相机检测输出（GUI 可切换）。

## 技术栈

TypeScript 5 · Three.js（含 EffectComposer / UnrealBloom / RoomEnvironment）·
lil-gui · Vite · Vitest · ESLint

## 快速开始

```bash
npm install
npm run dev
```

打开 Vite 输出的地址（默认 `http://localhost:5173`），在右上角 **生产控制** 面板
点击 **▶ 启动产线**。

### 控制面板

- **生产控制**：启动 / 停止产线（三工位联动），节拍倍率（0.5–2.5×）
- **视觉效果**：Bloom 辉光、环绕镜头、视觉预览工位切换、检测标记、坐标系、末端轨迹
- **关节手动调试**：选择机器人（ST1–ST3）、六轴角度、夹爪开度、回零/待机位

### HUD

左下角显示产线状态（产量 / 在制托架 / 节拍）与三个工位各自的实时状态；停线后
显示班报；左上角为所选工位的在线视觉检测面板。

npm test        # 27 项：图像处理(含黄色)、工位控制器状态机(含互锁)、自碰撞、三工位可达性
npm run lint

```

src/
├── assembly/    # 产线布局(纯几何)、零件建模、来料线、主线、工位控制器、状态屏

├── fx/          # 光环 / 火花特效

├── utils/       # 数学、坐标轴、日志工具
└── main.ts      # 组装根：三套工位装备 + 主线协调 + 运行循环

tests/unit/      # Vitest 单元与可达性测试
specs/           # 历史功能规格文档（v1.5 视觉分拣）
```
